## Selected Projects

### [Projectile Motion Simulator](https://github.com/ShOOmet14/projectile_motion_of_a_sphere)

Interactive Python desktop application for simulating and comparing projectile motion models, including linear and quadratic air resistance.

The project combines numerical integration, physical modelling, data visualisation, GUI development, automated testing, and simulation data export.

**Technologies:** Python, NumPy, Matplotlib, PySide6, pytest, GitHub Actions

### [Electric Field - Point Charges](https://github.com/ShOOmet14/electric-field-point-charges)

Python simulation of the electric field generated by multiple point charges on a two-dimensional plane.

The project uses the superposition principle to calculate the resulting electric field and visualises the charge configuration and field vector.

**Technologies:** Python, NumPy, Matplotlib

### [Laplace Equation - Electric Potential](https://github.com/ShOOmet14/laplace_equation_electric_potential)

Computational physics project focused on electric potential and the Laplace equation.

Detailed documentation of the physical model and numerical approach is currently being prepared.
